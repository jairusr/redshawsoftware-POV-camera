# VITURE SDK notice

This repository contains an independently written JNI adapter for the publicly documented VITURE Camera Provider ABI. It does not contain or redistribute VITURE SDK headers, libraries, sample source, or documentation.

To use the integration, apply for and obtain the Android Glasses SDK directly from VITURE, and ensure your use is authorized under VITURE's terms. The local installer intentionally places `libglasses.so` in a Git-ignored directory.
